# Plex Media Manager 0.1.5.0

Versions before 0.2.0.0 were deployed by commit; these notes were written afterwards (2026-11-23).

### New
- **Two ways to manage subtitles.** Bazarr (as before) or PMM's own wanted-subtitles profile (`subtitle_profile_default`, `_anime`, `_foreign`), chosen with `subtitle_source` (auto, bazarr or local). Reports say which source decided; `pmm scan --compare-sources` plans each file both ways and shows where they differ, and an *Import from Bazarr* button fills the profile from Bazarr's language profiles.
- **Subtitle formatting strip.** SRT subtitles can be kept at the bottom of the screen, with optional removal of colours and italics, bold and underline; a track that only needs this is planned as a remux, and held Bazarr items are left alone.
- **Worker GPU test** now reports the SSIM quality and size saving on a clip that HEVC can actually shrink.

### Fixed
- **The worker GPU test encodes its clip loosely** so that HEVC really runs (tested on a GTX 1080 Ti).
