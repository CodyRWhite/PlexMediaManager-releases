# Plex Media Manager 0.1.1.0

Versions before 0.2.0.0 were deployed by commit; these notes were written afterwards (2026-11-23).

### New
- **Workers that share a machine with Plex can pause.** Each worker can have pause hours (`--pause-hours 16:00-23:30`) and pause while Plex has N transcodes; a paused worker takes no new files and its running encode is frozen and resumed later.
- **GPU-first routing of conversions.** Unoptimised conversions go to GPU workers, CPU (x265) workers take only what no GPU worker can do, and a GPU worker hands a file back untouched when NVENC cannot make it smaller and visually lossless.
- **The Docker image runs with PUID, PGID, UMASK and TZ variables**, like the Sonarr and Radarr images, so files it rewrites keep their owner.
- **Synology install guide and tested compose file** with step-by-step DSM 7.2 Container Manager instructions, and an option to give the container its own IP on an existing macvlan network with media at Plex's paths.

### Fixed
- **Whisper picks the precision each GPU supports** (8-bit on a GTX 1080 Ti, 16-bit on RTX 20-series and newer) instead of refusing to load.
- **NVENC uses only the optional settings each GPU accepts**, so a card that rejects one option no longer falls back to slow x265.
- **NVENC settings remember the GPU they were tested on**, and a machine with a different GPU searches again on its own card.
- **A paused worker no longer loses its job.** Workers check in every 15 seconds while a task runs, so a frozen encode is not marked failed after 10 minutes.
- **GPU names show inside the Flatpak**, files without size tags (MKVs muxed by FFmpeg) are converted, and preview clips work without libx264.
