# Plex Media Manager 0.1.3.0

Versions before 0.2.0.0 were deployed by commit; these notes were written afterwards (2026-11-23).

### New
- **Workers can be set up on Fedora, Bazzite and RHEL.** `setup-worker.sh` checks the machine, installs the NVIDIA extension matching the driver and prints the steps for the distribution; a loaded driver without its extension is reported in the worker page, its log and the main app.
- **Always-on switch on the worker page** ("Start this worker when I log in"), through the desktop's background portal in the Flatpak.
- **About pages** on the main app and the worker with the version, exact build, how it is installed, the machine (system, CPU, memory, GPU, driver), uptime, data folder, database size and scratch space.
- **Foreign dialogue is never missed, made-up languages included.** Forced subtitles can be made from the film's own full subtitles (each line's audio gets a language check, and picture subtitles are read with OCR), Whisper flags speech in no known language instead of translating it into nonsense, and an English film never loses its only English subtitles when no forced ones can be had.

### Fixed
- **Workers in the media's group can use the trash.** The trash folder copies its parent's group write, and SMB access errors now say that the NAS decides for the credentials' user.
- **Thor: The Dark World no longer loses its only subtitle track.** TMDB lists only English for it, so no forced subtitles were sought; OpenSubtitles is now searched whatever TMDB says.
