# Plex Media Manager 0.7.0.1

### Fixed
- **Safari no longer gets stuck on "PMM is offline".** One failed page load (the server restarting during an update, an iPad or iPhone waking up before its network is back) showed the offline page, and it only tried again when the browser reported going from offline to online, which it never did, so it stayed there while the server was up. The offline page now checks the server by itself every 10 seconds, when it is shown again and on **Try again**, and as soon as the server answers it removes the app's service worker and stored files and opens the app (the app installs them again). Opening a page now tries the server a second time before giving up, passes redirects (such as to the sign-in) on in the form Safari accepts, and leaves the sign-in pages (`/login`, `/setup`, `/auth/...`, a worker's `/sso`) and `/api/` to the browser. The app asks for the service worker without the browser's cache, so this fix reaches installed copies at the next visit.
