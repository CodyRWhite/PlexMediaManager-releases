# Plex Media Manager 0.1.6.0

Versions before 0.2.0.0 were deployed by commit; these notes were written afterwards (2026-11-23).

### New
- **Library index and Library pages.** Every file has one row with a state for video, audio and subtitles, an overall status and a one-line summary, kept current after dry runs, commits and restores. The Library has a file list with To do, Waiting, Needs review, Done, Failed and All tabs, Movies / TV / All, search, sort and multi-select with *Apply selected* (admins), TV by series and season, and a deep-linkable page per file with tracks, review notes, history with restore, *Re-analyse* and *Apply this*.
- **PMM's own subtitle downloads** (Path B) work without Bazarr. Candidates from OpenSubtitles are scored (hash, ids, release, frame rate, hearing-impaired, trust, downloads), tried best first until one passes the timing check, retried with backoff, upgraded later, and kept within the daily download quota.
- **Films without dialogue** (all main audio tracks marked zxx) want no subtitles and count as complete on both subtitle paths.
- **Commits can take planned files from several dry runs** in one job.

### Fixed
- **Discord notifications work again.** Notifications now send an app user agent (Discord answered 403 to Python's default one), and the test button shows the reason when it fails.
- **Downloaded full subtitles get the same default flag** as an embedded track would, and an upgrade keeps the flags of the track it replaces.
- **PMM's own pending downloads show when they will next be tried**: the library waits until the next search or the quota reset instead of showing a placeholder.
