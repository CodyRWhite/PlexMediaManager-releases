# Plex Media Manager 0.1.2.0

Versions before 0.2.0.0 were deployed by commit; these notes were written afterwards (2026-11-23).

### New
- **Accounts and login.** The first visit creates the account (scrypt-hashed password), then a login page with 30-day sessions; failed logins are limited and `pmm reset-password` fixes a lockout.
- **Settings in the database.** 67 settings with types and limits are saved in the database, applied without a restart, with secrets write-only; the Settings tab also holds worker keys and the Plex webhook address.
- **A key per worker**, created in the UI, stored hashed, revocable, with its last use shown. Compose files no longer carry a password or shared token.
- **Worker settings and status page.** Each worker serves its own page (127.0.0.1:8766) with its connection, current file and progress, pauses, GPU, encoders and recent files, and keeps its settings (main app address, key, name, path map, encoder, scratch folder, pause rules, Whisper model) in its own database.
- **Burned-in subtitle check.** Before a subtitle line is added, the frames behind it are read with Tesseract OCR; lines already burned into the picture are left out and unclear films are held for review in the Library (Yes / No, undoable, `pmm burned-in`).
- **Existing forced subtitles are recognised** next to the video (for example `Thor (2011).en.forced.srt`), and TMDB's spoken languages stop Whisper from listening to films that are English only.
- **The Docker image is published to GHCR** (`ghcr.io/codyrwhite/plexmediamanager`, for amd64 and arm64) and the compose files pull it.

### Fixed
- **Write access is checked before any work on a file.** A worker that cannot write to the NAS no longer runs Whisper first and then fails moving the original to the trash; the error names both user ids.
- **Forced subtitles are timed more precisely** against the film's full English subtitles, then the speech, then the foreign speech.
- **Build folders are kept out of the Flatpak and Docker builds**, which stopped a 2.5 GB folder from stalling the build.
- **The top bar wraps on phones** instead of scrolling sideways.
