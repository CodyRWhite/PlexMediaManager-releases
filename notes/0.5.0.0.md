# Plex Media Manager 0.5.0.0

### New
- **Global search**: Ctrl+K (Cmd+K on a Mac), or the search button in the top bar, finds films, series, seasons and episodes as you type, and also Settings and System pages and individual settings by name. Arrow keys, Enter and Esc work; recent searches are kept per user in the browser. New `GET /api/search`.
- **Notification bell** in the top bar: what Discord and the other channels are told (finished applies, failed jobs, files that failed their check, films waiting for review, workers paused for heat, failed scheduled backups) is also kept in the app, with an unread count, links to the page concerned and read marks per account. Setting: Notifications to keep in the bell (200). New table `notifications` and `notification_reads`.
- **Settings search**: a box on the Settings page finds a setting by label or help text across all tabs and jumps to it.
- **Installable app (PWA)**: web manifest, icons and a service worker that keeps only the app shell, so PMM starts offline with a "PMM is offline" page. Nothing from `/api/` is ever cached.
- **Bottom navigation bar** on phones (600 px and narrower) in place of the top tabs.
- **Setup wizard** for a first run (Plex, Sonarr and Radarr, subtitles, libraries, workers, sign-in): opens for the first admin when nothing is configured, can be skipped, closed and continued, and run again from Settings, Account.
- **Live activity** on the Overview: worker cards (current file, progress, fps, time left, GPU temperature and power, pause reason), the indexing rate and the queue size, pushed over server-sent events with reconnect and a polling fallback; shutdown is not held up by open streams.
- **Smart views** on the Library: 4K not HEVC, Biggest savings, Missing forced subtitles, Made-up languages, Changed this week, Season inconsistent, and your own saved filters, each with a count and Apply all.
- **Before and after** on the item page (all layouts) with space saved and estimated time; the Apply dialog totals the selection (files, GB before, after and saved, time on the online workers).
- **Insights** page (`/insights`): codec mix, space reclaimed over time, subtitle coverage, audio language mix and a per-library breakdown, drawn as accessible inline SVG from a cached aggregate.
- **Release notes** page (About, Release notes, `/releases`) with every version's New, Fixed and Changed lists, and a **What's new** dialog shown once per user after an upgrade (not on a fresh install). The changelog is shipped with the app.
- **System, Updates** (admins): the installed version against the latest on the chosen channel (Release or Develop) with *Installed*, *Latest* and *Update available* badges, the release list from the public feed with highlights and notes links, the workers' versions against the main app (outdated and incompatible ones flagged), and how to update. A dot on the About button shows an available update. The main app only looks the feed up (5 second timeout, cached 6 hours, a soft warning when it fails) and never updates itself. Settings, System, Updates: **Check for updates** and **Update channel**.
- **Export and import settings** (Settings, System, admins): one JSON file with all settings, the libraries, layouts and each user's own appearance. Secrets are left out unless chosen (and then the file is marked). An import is validated, shown as a preview grouped by Settings tab (secrets only as "will be set/changed") and applied on confirmation; unknown keys are reported, not applied; it is audit-logged.

### Fixed
- The top bar wraps onto a second row instead of pushing the page sideways when the window is narrower or the language longer.

### Changed
- The database gets two new tables (`notifications`, `notification_reads`), created at start-up.
- The library index gets three columns (`conlang`, `audio_langs`, `sub_langs`) and a partial index, filled once in the background from stored plans at the first start. Back up before upgrading, as always.
