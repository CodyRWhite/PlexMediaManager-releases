# Plex Media Manager 0.1.7.0

Versions before 0.2.0.0 were deployed by commit; these notes were written afterwards (2026-11-23).

### New
- **Sign in automatically** with OpenID Connect: a signed-out visitor goes straight to the provider (Authentik) and back to the page they asked for, and the password form sits behind a "Use password instead" link. The new setting `oidc_auto_login` is on by default, and API calls still get a 401.
- **Library artwork from Plex.** Posters, backdrops, stills and series posters are fetched through Plex (the token stays on the server) and cached on disk with a size cap (`plex_art_cache_mb`).
- **Switchable Library layouts.** The item page can be Classic, Cinematic, Sidebar or Glass and the list can be rows or a poster grid; each user's choice is saved, and Settings, Appearance sets everyone's default. A new layout is one file plus one registry line.
- **Previous and next episode** links on the item page, and a made-up-language signal in the item details.

### Fixed
- **Foreign films keep the original-language audio, not the dub.** The original language comes from Radarr or Sonarr, then TMDB, then the track flagged as original, then the only non-English language; with several and no way to tell, all are kept and the plan says so.
- **Styled ASS subtitles keep their placement and effects.** The position, colour and italic strip switches no longer touch ASS/SSA tracks, and their clean-up only drops blank untagged events, plain ads and exact duplicates.
- **Signing in from the plain login page lands on the home page**, not back on the login page.
- **The Library item page has even spacing** between panels and equal-height rows, and the Library navigation is readable over backdrops.
