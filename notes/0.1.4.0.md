# Plex Media Manager 0.1.4.0

Versions before 0.2.0.0 were deployed by commit; these notes were written afterwards (2026-11-23).

### New
- **Bazarr-driven clean-up.** PMM asks Bazarr whether an item's subtitles are complete before touching it, removes unwanted subtitle files next to the video, and handles audio with its own settings. An item counts as complete when only forced English is missing and an embedded forced PGS exists.
- **Picture (PGS) forced subtitles become text.** A forced PGS track is replaced by a validated SRT or OCR text track after a timing match against the existing subtitles.
- **Films that will never get forced subtitles.** When Bazarr lists only English forced as missing forever, PMM waits (`forced_missing_wait_days`, default 30) and then decides locally: it makes forced subtitles from the full ones, or removes all subtitles when there is no foreign dialogue, or holds the file for review.
- **Made-up languages are never treated as English-only.** Language tags such as "[speaking Klingon]", non-English text, non-natural language codes and a list of known titles (`conlang_titles`) keep subtitles in place, and a forced track is built from the tagged lines.
- **Sign in with Authentik (OpenID Connect).** Accounts have admin and view-only roles from the provider's admin group, local password sign-in can be turned off once an admin has signed in through OIDC, and `PMM_FORCE_LOCAL_LOGIN=1` brings it back.
- **Workers stop gracefully.** On a stop the worker cancels its running tool, deletes its scratch files and hands the file back to the main app at once.
- **`pmm scan --apply` notifies Plex, Sonarr, Radarr and Bazarr** after a change, as the web UI does.

### Changed
- **The Settings page is redesigned** with tabs per group in task order, units and percentages, an Advanced part, conditional settings, a "set / not set" badge, connection checks with a test button, unsaved-change dots and a phone layout. Sonarr and Radarr have their own sections.
- **Subtitle downloads by PMM pause while Bazarr is set up**, and the Settings page says so.

### Fixed
- **Held items never get subtitle properties edited**, and the plan report shows which properties an edit would change.
- **A forced track with too few lines** is reported as "not measured" instead of "left unchanged for review".
- **The worker service stops cleanly.** `systemctl stop` no longer leaves the old worker holding its port, its log lines are tagged `pmm-worker` and written whole, and About shows the worker's real scratch folder, including the free space of one that does not exist yet.
