# Plex Media Manager 0.8.0.0

### New
- **The rest of the interface follows your language.** Texts the server writes now translate too: why a track is kept or removed, plan warnings and the Library's one-line summaries, why a worker is paused and what it is doing ("extracting subtitles 42%"), Health details, Problem file reasons, every bell notification, scheduled task results, the whole Settings page (labels, help texts, choices, sections) and error messages. Files analysed before the upgrade translate as well. Logs, the CLI and Discord stay English.
- **Language names in your language.** The item page and Insights show a track's language by name in the language you chose instead of a code, and the special codes read as words: *No dialogue* (zxx), *Unknown language* (und), *Several languages* (mul).
