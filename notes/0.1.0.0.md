# Plex Media Manager 0.1.0.0

Versions before 0.2.0.0 were deployed by commit; these notes were written afterwards (2026-11-23).

### New
- **MKV audio and subtitle clean-up.** Non-anime files keep the best English audio and English forced subtitles; anime keeps the English dub first, then the native audio, with forced and full English subtitles. Changes are made in place with mkvpropedit where possible and with a verified remux otherwise.
- **Forced-subtitle sync with a confidence check.** PMM's own aligner (voice detection and cross-correlation) measures timing against the full English track, refuses low-confidence corrections and detects frame-rate drift. Picture (PGS) subtitles can serve as the reference.
- **Web UI** with a dry run you review before committing: folder browser, per-file track review, selective commit, live progress, cancel, an activity log and a hardware panel. A commit refuses files changed since the dry run.
- **Quality-checked HEVC conversion** (x265, NVENC, VideoToolbox) that only keeps a result that is smaller and stays visually lossless (VMAF and SSIM floor), plus MP4, AVI and TS to MKV without re-encoding. Files that are not HEVC or not MKV are flagged.
- **Settings optimiser** that tests quality settings on samples across the film, picks one for best quality, balanced or most savings, and shows matching frames, difference images and a real HEVC preview clip.
- **Remote workers** run conversions on other machines through the network share (`pmm worker`), with a token-protected worker API and a Workers panel.
- **Library dashboard, History with restore and a trash.** Results are stored and paged, interrupted runs resume, originals go to a drive-level trash with one-click restore, and the Library shows charts and what needs attention.
- **Plex, Sonarr, Radarr and notifications.** PMM pauses work while someone is watching in Plex, refreshes the changed folder, rescans in Sonarr and Radarr, supports an automatic mode for new files, and notifies through Discord, ntfy, Pushover or a webhook.
- **Subtitle clean-up** removes ads and watermarks, repairs mis-decoded text, drops empty lines and merges repeats, with an optional hearing-impaired tag removal.
- **Missing subtitles can be found or generated** with OpenSubtitles and Whisper (faster-whisper) on workers that support it.
- **Flatpak and Docker packages** for SteamOS and a Synology NAS, with a Whisper extension for GPU machines.
