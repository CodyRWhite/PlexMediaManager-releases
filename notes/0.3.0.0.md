# Plex Media Manager 0.3.0.0

### New
- The web UI can be translated (phase 1): each user picks a language in Settings, Account; English is complete and other languages can be added as JSON files (see docs/ui.md). Server-side texts and the command line stay English for now.
- Themes: System, Light or Dark per user, plus custom themes (presets Plex orange, High contrast and OLED black, live preview with contrast checks, import/export as JSON), with no flash of the wrong theme; light and dark colours now meet WCAG AA contrast.

### Fixed
- Subtitles held for your burned-in review no longer count as a failed search: once you decide, the next run adds them instead of waiting a day.
- Text that was hard to read in the light theme (accent text, warnings, the Commit button) now has enough contrast.
- The Settings tabs wrap onto a second line instead of being cut off, and Settings panels fit narrow phones, in any language.

### Changed
- The code is reorganised into smaller modules, with no change in behaviour.
- Every pull request and develop build now runs the full test suite with the real media tools, plus browser tests of every page in light and dark at desktop and phone size; a failing run blocks the Docker image.
- Browsers check for updated scripts and styles on every load, so an upgrade never shows a stale page.
